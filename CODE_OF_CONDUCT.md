# Código de Conducta

## Nuestro compromiso

Este proyecto existe por una emergencia en la que murieron y desaparecieron personas.
Quienes contribuyen pueden ser familiares de víctimas, socorristas que vienen de un turno
de rescate, o voluntarios agotados. El tono importa tanto como el código.

Nos comprometemos a que participar aquí sea una experiencia libre de acoso para todas las
personas, sin importar edad, apariencia, discapacidad, etnia, identidad o expresión de
género, nivel de experiencia, nacionalidad, religión, orientación sexual o situación
socioeconómica.

## Comportamiento esperado

- Usar lenguaje acogedor e incluyente, en español o inglés.
- Respetar puntos de vista y experiencias distintas.
- Aceptar la crítica constructiva sin tomarla como algo personal.
- Recordar que del otro lado hay alguien que también está dando su tiempo gratis.
- Tener especial cuidado al hablar de víctimas, personas desaparecidas y sus familias.
  No son casos de prueba ni datos de ejemplo.

## Comportamiento inaceptable

- Acoso público o privado, insultos o ataques personales.
- Comentarios despectivos sobre las víctimas, las comunidades afectadas o los grupos de socorro.
- Publicar datos personales de terceros sin autorización, dentro o fuera del repositorio.
- Usar el proyecto o sus canales para difundir desinformación sobre el desastre.
- Intentar usar el proyecto, sus datos o su nombre para estafar o captar dinero de familias afectadas.

## Aplicación

Quien mantiene el proyecto puede editar o eliminar comentarios, commits, código, issues y
cualquier otra contribución que no cumpla este código, y puede bloquear temporal o
permanentemente a quien tenga comportamientos inaceptables.

Para reportar un problema, abre un issue privado con quien mantiene el repositorio o
escribe al correo de contacto listado en el perfil del proyecto. Todos los reportes se
revisan y se tratan con reserva.
